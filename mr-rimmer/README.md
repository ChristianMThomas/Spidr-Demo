# mr-rimmer — Project Second Brain

This folder is Spidr's institutional memory: the "principal senior engineer" who knows the project through and through. Each file is a deep reference on one domain, written from the *actual code*, with file:line citations so claims can be verified.

Rules for documents in here:
- **Code is the source of truth.** Every claim should be traceable to a file/line. Date-stamp each doc and note the branch it was audited on.
- **Record gaps and risks, not just facts.** If the code contradicts the UI copy or the intended design, say so explicitly.
- **Update on change, don't fork.** When a domain shifts (new patch, refactor), revise the existing doc rather than adding a second one.
